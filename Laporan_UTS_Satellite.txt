A. Deskripsi Proyek & Kode Utama

Proyek "Satellite Simulator" merupakan simulasi 3D interaktif yang menampilkan Bumi beserta tiga satelit (Aqua, ICESat-2, dan Landsat 8) yang mengorbit dengan perhitungan kecepatan dan inklinasi yang mendekati riil. Simulasi ini dibangun di atas OpenGL dan C++ dengan memanfaatkan GLM untuk kalkulasi matriks kompleks. Keseluruhan aplikasi diatur melalui mekanisme State Machine (Mesin Status) dalam loop perenderan.

Berikut adalah pondasi utama pada `main.cpp` yang berfungsi sebagai pengontrol siklus hidup simulasi:

```cpp
void Starfield::render(const Camera& camera, float time) {
    glDepthMask(GL_FALSE);
    shader.bind();
    
    // Potong translasi matriks menjadi mat3
    glm::mat4 view = glm::mat4(glm::mat3(camera.getViewMatrix())); 
    shader.setUniformMatrix4fv("u_view", view);
    shader.setUniformMatrix4fv("u_projection", camera.getProjection());
    shader.setUniform1f("u_time", time);

    glEnable(GL_PROGRAM_POINT_SIZE);
    glBindVertexArray(VAO);
    glDrawArrays(GL_POINTS, 0, starCount);
}
```
Penjelasan:
Program menghindari penggunaan model latar kubus gambar (Skybox Bitmap) berukuran berat dan menggantinya dengan generasi prosedural vertex 2500 primitif poin tunggal (`GL_POINTS`). Untuk memberikan kesan kedalaman luar angkasa yang amat masif tanpa batas, metode *Depth Buffer Writing* (`glDepthMask`) diblokir sementara agar bintang berada murni secara kosmetik di balik seluruh benda material scene. Teknik utamanya ada pada pemotongan komponen translasi matriks kamera dari 4x4 menjadi 3x3. Pemotongan baris vektor pergeseran spasial ini menjadikan tumpukan titik bintang hanya terpengaruh oleh aksi toleh/putar dari pandangan kamera, tetapi takkan pernah bisa didekati (karena sumbu X, Y, Z kameranya dicabut). Inilah yang menciptakan ilusi *Infinity Parallax Depth* dari jagat raya.

7. Lapisan Sinar Atmosfer Bumi (Fresnel Rim Glow)
Source code (atmosphere.frag):
```glsl
void main() {
    vec3 viewDir = normalize(u_viewPos - FragPos);
    float fresnel = dot(viewDir, normalize(Normal));
    fresnel = clamp(1.0 - fresnel, 0.0, 1.0);
    fresnel = pow(fresnel, 4.0); 

    vec3 lightDir = normalize(u_lightDir);
    float diffuse = max(dot(normalize(Normal), lightDir), 0.0);
    
    vec3 atmosColor = mix(vec3(0.02, 0.1, 0.3), vec3(0.4, 0.7, 1.0), diffuse);
    FragColor = vec4(atmosColor, fresnel * 0.8 * (diffuse + 0.1));
}
```
Penjelasan:
Selain bola planet solidnya, sebuah bola tak bertekstur dengan rentang radius beberapa unit lebih raksasa ditumpukkan di titik yang sama secara semi-transparan mode Additive Blending. Di dalam mikrokontrolernya (Shader), shader ini mematuhi rasio hukum fisika *Fresnel Dot Product*. Sudut Normal (Arah tegak lurus lekukan bumi) di-skalarkan tehadap Sudut Penglihatan Kamera (View Direction). Jika keduanya tegak lurus satu sama lain (bernilai nol, artinya berada di pinggir bola), warna alpha Fresnel diinversikan mendekati maksimal (1.0). Ini membuat aura cahaya kebiruan hanya menebal sangat jelas menyala menyelimuti lengkungan kurva tepi bola dan lenyap transparan di bagian tegak lurus dada bola ke arah pengguna. Lapisan atmosfer ini juga secara cerdas diredupkan kepadatannya ketika terpapar di sisi yang miskin cahaya matahari (*night shadow side*).

```cpp
for (int i = 0; i < (int)orbits.size(); i++) {
    std::vector<float> lineVerts;

        lineVerts.push_back(pos.x);
        lineVerts.push_back(pos.y);
        lineVerts.push_back(pos.z);
    }

}
```
Penjelasan:

9. Dinamika Kinematika Translasi Satelit 3D
Source code (SatelliteScene.cpp):
```cpp
void SatelliteScene::update(float deltaTime) {
    for (int i = 0; i < (int)orbits.size(); i++) {
        OrbitData &od = orbits[i];
        
        od.currentAngle += od.speed * deltaTime * timeScale;
        
        float x = od.radius * cosf(od.currentAngle);
        float z = od.radius * sinf(od.currentAngle);
        glm::vec3 rawPos = glm::vec3(x, 0.0f, z);

        glm::mat4 incMat = glm::rotate(glm::mat4(1.0f), glm::radians(od.inclination), glm::vec3(0, 0, 1));
        glm::vec3 finalPos = glm::vec3(incMat * glm::vec4(rawPos, 1.0f));
        od.pos = finalPos;

        glm::mat4 model = glm::mat4(1.0f);
        model = glm::translate(model, finalPos);
        model = glm::rotate(model, glm::radians(od.inclination), glm::vec3(0, 0, 1));
        model = glm::rotate(model, -od.currentAngle, glm::vec3(0, 1, 0));
        model = glm::scale(model, glm::vec3(od.scale));
        
        od.modelMatrix = model;
    }
}
```
Penjelasan:
Kunci fundamental seluruh kinetik ruang benda 3D ada pada cuplikan modul di atas. Titik spasial mentah x dan z dihitung dari perkalian jarak jauh satelit (Radius) dengan sudutnya yang bervariasi setiap frame. Transformasi akhir sebuah benda grafika mutlak membutuhkan Matriks Model terpadu (Matrix 4x4) sebelum dilempar ke kartu grafis. Setelah memperoleh titik posisi ruang melingkarnya (yang juga sudah dikalikan dengan rotasi inklinasi Z agar letaknya presisi bertumpuk di atas rel `orbit trails`), model digeser (`translate`), lalu dirotasi ganda, pertama menunduk sesuai kemiringan rel, lalu membelok seiring sudut putarnya, menjamin desain model antena satelit konsisten menghadap ke laju putaran layaknya pesawat nyata. Barulah kemudian objek diperkecil (`scale`) agar relevan dengan ukuran proporsi simulasi jagat raya.

11. Mode Sudut Pandang Penjelajah (Free Fly Camera)
Source code (Camera.cpp):
```cpp
void Camera::processKeyboardInput(GLFWwindow *window) {
    if (chaseMode) return; // Mode bebas dinonaktifkan saat mengunci satelit

    float speed = 8.0f * deltaTime;
    glm::vec3 right = glm::normalize(glm::cross(cameraFront, cameraUp));

    if (glfwGetKey(window, GLFW_KEY_W) == GLFW_PRESS)
        cameraPos += speed * cameraFront;
    if (glfwGetKey(window, GLFW_KEY_S) == GLFW_PRESS)
        cameraPos -= speed * cameraFront;
    if (glfwGetKey(window, GLFW_KEY_A) == GLFW_PRESS)
        cameraPos -= right * speed;
    if (glfwGetKey(window, GLFW_KEY_D) == GLFW_PRESS)
        cameraPos += right * speed;

    view = glm::lookAt(cameraPos, cameraPos + cameraFront, cameraUp);
}
```
Penjelasan:
Mode bebas (Free Fly Mode) ini diizinkan selama pengguna tidak sedang membidik mengawasi satu satelit satupun. Logikanya berjalan seperti kerangka mekanik pergerakan orang pertama dalam desain permainan interaktif (First Person). Arah depan ditetapkan dengan vektor statis, sedangkan pergerakan geser samping *strafing* menyapu koordinat kiri (A) dan kanan (D) diturunkan secara brilian dengan mengeksploitasi fungsi matematika produk silang *Cross Product* dari penunjuk kamera ke depan dan garis pandu tegak lurus bumi (Up Vector), yang menghasilkan persis garis tegak lurus ke samping.


12. Algoritma Fokus Interpolasi Mulus (Chase Camera Mode)
Source code (Camera.cpp):
```cpp
if (chaseMode) {
    glm::vec3 up(0.0f, 1.0f, 0.0f);
    glm::vec3 toTarget = glm::normalize(chaseTarget);
    
    // Tentukan titik Offset koordinat di belakang dan atas buritan
    glm::vec3 offset = glm::normalize(toTarget) * 6.0f + glm::vec3(0.0f, 3.0f, 0.0f);
    glm::vec3 desiredPos = chaseTarget + offset;

    // Linear Interpolation (Lerp) untuk Smoothing Panning
    float smoothSpeed = std::min(1.0f, 4.0f * deltaTime);
    cameraPos += (desiredPos - cameraPos) * smoothSpeed;

    view = glm::lookAt(cameraPos, chaseTarget, up);
    return;
}
```
Penjelasan:
Ketika fokus ditarik ke sebuah sasaran (dengan menekan nomor urut 1, 2, atau 3), operasi kamera model pendaratan FPS di-bypass mutlak oleh segmen perulangan kode ini. Mesin mencari *Desired Position* alias posisi ideal bagi kameramen yang ditetapkan membuntuti statis di koordinat tepat enam satuan langkah dari buritan mesin dan tiga pilar menjulang di atapnya (Offset). Demi mencegah fenomena perpindahan mendadak posisi dunia yang membuat mual atau merusak ilusi (Jitter Snapping), `cameraPos` saat ini tidak langsung disamakan dengan tujuan. Pergeseran diinterpolasikan fraksional secara linier (Lerp - Linear Interpolation) setiap milidetiknya. Alhasil, lensa perlahan-lahan mengayun tergelincir masuk meluncur mulus menstabilkan letaknya, mengekor sasaran satelit secara natural seperti dalam karya rekam industri perfilman sinematik (Cinematic Camera Handling).

```cpp
void SatelliteScene::renderMinimap(const Camera &camera, int screenW, int screenH) {
    int mapSize = 160;
    int mapX = screenW - mapSize - 20;
    int mapY = screenH - (mapSize * 2);

    glViewport(mapX, mapY, mapSize, mapSize);
    glScissor(mapX, mapY, mapSize, mapSize);
    glEnable(GL_SCISSOR_TEST);

    glClearColor(0.01f, 0.02f, 0.05f, 1.0f);
    glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);

    float viewRange = 25.0f;
    glm::mat4 orthoProj = glm::ortho(-viewRange, viewRange, -viewRange, viewRange, -100.0f, 100.0f);
    glm::mat4 topView = glm::lookAt(glm::vec3(0, 60, 0), glm::vec3(0, 0, 0), glm::vec3(0, 0, -1));

    orbitShader->bind();
    orbitShader->setUniformMatrix4fv("u_view", topView);
```

22. Arsitektur Pencahayaan Matahari Direksional (Directional Sun Light System)
Source code (SatelliteScene.cpp & phong.frag):
```cpp
// Dari SatelliteScene.cpp — Konstruktor: Definisi Sumber Cahaya Matahari
glm::vec3 sunPos(200.0f, 100.0f, 200.0f);
sunLight = {
    glm::normalize(-sunPos),                // direction toward scene
    glm::vec3(0.08f, 0.08f, 0.10f),         // ambient
    glm::vec3(1.0f,  0.95f, 0.85f),         // diffuse
    glm::vec3(0.5f,  0.5f,  0.45f)          // specular
};

// Dari SatelliteScene.cpp — setLights(): Upload Uniform ke GPU
void SatelliteScene::setLights(Shader &shader) const {
    shader.setUniform3f("dirLight.direction", sunLight.direction.x, sunLight.direction.y, sunLight.direction.z);
    shader.setUniform3f("dirLight.ambient",   sunLight.ambient.r,  sunLight.ambient.g,  sunLight.ambient.b);
    shader.setUniform3f("dirLight.diffuse",   sunLight.diffuse.r,  sunLight.diffuse.g,  sunLight.diffuse.b);
    shader.setUniform3f("dirLight.specular",  sunLight.specular.r, sunLight.specular.g, sunLight.specular.b);
}

// Dari phong.frag — Struct Definisi Cahaya Direksional
struct DirLight {
    vec3 direction;
    vec3 ambient;
    vec3 diffuse;
    vec3 specular;
};

// Dari phong.frag — Fungsi Kalkulasi Pencahayaan Direksional
vec3 calcDirLight(DirLight light, vec3 normal, vec3 viewDir,
                  vec3 baseDiffuse, vec3 baseAmbient)
{
    vec3 lightDir = normalize(-light.direction);
    vec3 ambient = light.ambient * baseAmbient;

    float diff = max(dot(normal, lightDir), 0.0);
    vec3 diffuse = light.diffuse * diff * baseDiffuse;

    vec3 halfwayDir = normalize(lightDir + viewDir);
    float spec = pow(max(dot(normal, halfwayDir), 0.0), material.shininess);
    vec3 specular = light.specular * spec * material.specular;

    return ambient + diffuse + specular;
}
```
Penjelasan:
Matahari dalam simulasi ini bukanlah sebuah sumber cahaya titik (*Point Light*) yang melemah seiring jarak, melainkan dimodelkan sebagai sumber cahaya direksional (*Directional Light*) yang mensimulasikan sinar paralel tak terhingga jauhnya, sebagaimana sifat asli cahaya matahari di dunia nyata yang datang dari jarak 150 juta kilometer sehingga sinarnya bisa dianggap sejajar sempurna. Posisi abstrak matahari ditetapkan di koordinat `(200, 100, 200)` yang kemudian dinormalisasi dan dibalik arahnya (`-sunPos`) untuk mendapatkan vektor arah cahaya yang menyinari ke pusat scene. Komponen pencahayaan disusun dalam tiga lapis: *ambient* bernilai sangat rendah `(0.08, 0.08, 0.10)` memberikan iluminasi dasar gelap agar sisi malam Bumi tidak sepenuhnya hitam pekat, *diffuse* bernilai hangat kekuningan `(1.0, 0.95, 0.85)` mereplikasi spektrum cahaya matahari sesungguhnya yang sedikit condong ke arah warna kuning-putih, dan *specular* bernilai moderat `(0.5, 0.5, 0.45)` untuk kilau pantulan permukaan lautan. Di dalam *Fragment Shader*, perhitungan menggunakan model Blinn-Phong dengan vektor *halfway direction* (`halfwayDir`) sebagai pengganti refleksi murni, menghasilkan distribusi kilau spekular yang lebih realistis dan secara komputasi lebih efisien daripada model Phong klasik. Dot product antara normal permukaan dan arah cahaya menghasilkan faktor difus yang secara alamiah menciptakan transisi gradual antara sisi terang (siang) dan sisi gelap (malam) pada permukaan Bumi.

Penjelasan:
Matahari sebagai sumber cahaya utama alam semesta tidak boleh terpengaruh oleh perhitungan pencahayaan dari sumber lainnya; ia harus bersinar mandiri. Objek matahari dibangun sebagai bola berdiameter 36 unit (radius 18.0f) yang diletakkan di koordinat `(200, 100, 200)`, cukup jauh dari pusat scene agar memberikan kesan skala jarak kosmik yang proporsional. Keajaiban sesungguhnya terletak pada variabel uniform `u_emissive` yang diinjeksikan tepat sebelum matahari di-render. Nilai emisi `(1.4, 1.1, 0.45)` sengaja ditetapkan melebihi rentang normal 1.0 (*over-bright*), menghasilkan efek bola cahaya yang menyilaukan dengan dominasi warna kuning-oranye panas. Dalam persamaan akhir fragment shader, nilai emissive ini dijumlahkan langsung (`result + u_emissive`) ke atas akumulasi pencahayaan konvensional, sehingga permukaan matahari secara harfiah "memancarkan" cahayanya sendiri tanpa bergantung pada sumber iluminasi manapun. Setelah matahari selesai di-render, uniform emissive segera direset ke `(0, 0, 0)` agar objek berikutnya tidak ikut bersinar mandiri.

Matriks rotasi `earthRot` kemudian langsung diterapkan sebagai *World Transform* dari objek Bumi. Stasiun darat (*Ground Station*) ditempatkan pada koordinat geografis riil Indonesia di lintang -2.5° Selatan dan bujur 115° Timur menggunakan konversi koordinat bola (*spherical-to-Cartesian*): rumus `cos(lat)*sin(lon)`, `sin(lat)`, `cos(lat)*cos(lon)` mengubah derajat lintang-bujur menjadi posisi tiga dimensi di permukaan bola. Posisi dasar ini kemudian dikalikan dengan matriks rotasi bumi yang sama (`earthRot * basePos`), menyebabkan stasiun darat ikut terseret berputar bersama permukaan planet persis seperti objek di dunia nyata yang menempel pada kerak bumi. Untuk orientasi model, sebuah basis ortogonal lokal dibangun: vektor "atas" (`up`) diarahkan radial menjauh dari pusat bumi, vektor "kanan" (`right`) diturunkan dari *cross product* dengan sumbu Y global, dan vektor "depan" (`fwd`) melengkapi sistem koordinat tangan kanan. Ketiga vektor ini disusun menjadi matriks orientasi `gsOrient` yang menjamin model piringan antena stasiun darat selalu berdiri tegak menghadap langit di manapun posisinya berada di permukaan bumi yang membulat.

```cpp
// Dari phong.frag — Fungsi Kalkulasi Spot Light dengan Soft Edge
vec3 calcSpotLight(SpotLightData light, vec3 normal, vec3 fragPos, vec3 viewDir, vec3 baseDiffuse) {
    vec3 lightDir = normalize(light.position - fragPos);
    float distance = length(light.position - fragPos);
    float theta     = dot(lightDir, normalize(-light.direction));
    float epsilon   = light.cutOff - light.outerCutOff;
    float intensity = clamp((theta - light.outerCutOff) / epsilon, 0.0, 1.0);
    if (intensity <= 0.0) return vec3(0.0);
    float attenuation = 1.0 / (light.constant + light.linear * distance + light.quadratic * distance * distance);
    float diff = max(dot(normal, lightDir), 0.0);
    vec3 diffuse = light.diffuse * diff * baseDiffuse;
    vec3 halfwayDir = normalize(lightDir + viewDir);
    float spec = pow(max(dot(normal, halfwayDir), 0.0), material.shininess);
    vec3 specular = light.specular * spec * material.specular;
    return (diffuse + specular) * attenuation * intensity;
}
```

Ketika pengguna mengaktifkan fitur ini melalui tombol 'F', setiap satelit memancarkan kerucut cahaya biru-sian (*cyan-blue*) `(0.4, 0.8, 1.0)` yang mengarah tepat ke permukaan Bumi. Sudut kerucut diimplementasikan dengan dua lapisan: *inner cutOff* sebesar 8 derajat menghasilkan inti kerucut yang terang pekat, dan *outer cutOff* sebesar 14 derajat menciptakan tepi gradual yang memudar halus (*soft edge falloff*). Orientasi kerucut geometri dihitung menggunakan *cross product* dan *arc cosine* antara vektor up default dan arah satelit-ke-Bumi, menghasilkan matriks rotasi yang mengarahkan kerucut secara presisi. // Dari update() — Animasi Partikel Transmisi Data dengan Deteksi LoS
```cpp
if (showParticles) {
    for (int s = 0; s < (int)particleT.size(); s++) {
        glm::vec3 satPos = orbits[s].pos;
        glm::vec3 rayDir = glm::normalize(groundStationPos - satPos);
        float rayLen = glm::length(groundStationPos - satPos);

        // Ray-Sphere Intersection: Cek apakah garis dari satelit ke stasiun menembus Bumi
        float tClosest = glm::dot(-satPos, rayDir);
        tClosest = glm::clamp(tClosest, 0.0f, rayLen);
        glm::vec3 closest = satPos + tClosest * rayDir;
        float distToCenter = glm::length(closest);
        bool hasLoS = (distToCenter > EARTH_RADIUS - 0.1f);

        for (int p = 0; p < NUM_PARTICLES; p++) {
            if (hasLoS) {
                particleT[s][p] += 0.45f * dt;
                if (particleT[s][p] > 1.0f) particleT[s][p] -= 1.0f;
            }
            // Tanpa LoS, partikel membeku — transmisi terhenti
        }
    }
}

// Dari render() — Rendering Garis Penghubung dan Paket Data
if (showParticles) {
    shader.setUniform3f("u_emissive", 0.3f, 0.25f, 0.0f);
    for (int s = 0; s < (int)orbits.size(); s++) {
        // ... deteksi LoS ulang ...
        if (!hasLoS) continue; // Lewati satelit tanpa garis pandang

        // Garis tipis penghubung satelit ke stasiun darat
        shader.setUniform1f("u_alpha", 0.12f);
        glm::vec3 mid = (satPos + groundStationPos) * 0.5f;
        // ... orientasi garis ...
        drawMesh(shader, particleMesh, particleMat, M);

        // Paket data bergerak sepanjang jalur
        for (int p = 0; p < NUM_PARTICLES; p++) {
            float t = particleT[s][p];
            glm::vec3 linear = glm::mix(satPos, groundStationPos, t);
            // Arc path: dorong keluar jika paket menembus permukaan Bumi
            glm::vec3 midDir = glm::normalize(linear);
            float minAlt = EARTH_RADIUS + 0.5f;
            float currentAlt = glm::length(linear);
            glm::vec3 pPos = (currentAlt < minAlt) ? midDir * minAlt : linear;
            drawMesh(shader, particleMesh, particleMat, glm::translate(glm::mat4(1.0f), pPos));
        }
    }
    shader.setUniform3f("u_emissive", 0.0f, 0.0f, 0.0f);
}
```

Penjelasan:
Fitur transmisi data (*Data Downlink*) mensimulasikan pengiriman paket informasi dari setiap satelit menuju stasiun darat di permukaan Bumi. Sebelum partikel data diizinkan bergerak, sistem melakukan pengecekan garis pandang (*Line-of-Sight* / LoS) menggunakan algoritma *Ray-Sphere Intersection* yang elegan. Sebuah sinar virtual ditarik dari posisi satelit menuju stasiun darat, kemudian program menghitung titik terdekat sinar tersebut terhadap pusat Bumi (origin). Jika jarak titik terdekat ke pusat Bumi lebih kecil dari radius Bumi, berarti sinar tersebut menembus badan planet — artinya Bumi menghalangi jalur transmisi (*occluded*), dan transmisi data dibatalkan. Ketika LoS tersedia, sejumlah `NUM_PARTICLES` partikel bergerak sepanjang jalur interpolasi linear (`glm::mix`) dari posisi satelit menuju stasiun darat. Parameter `t` setiap partikel bergerak maju secara konstan `(+0.45 * dt)` dan di-reset sirkular ketika mencapai 1.0, menciptakan aliran paket berulang. Untuk menghindari partikel yang secara visual menembus permukaan Bumi pada jalur transfer bersudut rendah, sistem menerapkan koreksi *arc path*: jika ketinggian partikel jatuh di bawah `EARTH_RADIUS + 0.5`, posisinya didorong keluar radial ke ketinggian minimum, menghasilkan lintasan melengkung yang mengikuti kurva permukaan Bumi. Secara visual, garis penghubung transparan (`alpha = 0.12`) ditarik antara satelit dan stasiun untuk menunjukkan jalur komunikasi aktif, dan partikel paket data diberi cahaya emissive kuning-emas `(0.3, 0.25, 0.0)` agar bersinar di kegelapan ruang angkasa.

```cpp
    orbits[i].pos = computeOrbitPos(orbits[i]);

    glm::vec3 pos = orbits[i].pos;

    orient[0] = glm::vec4(right,    0.0f);
    orient[1] = glm::vec4(corrUp,   0.0f);
    orient[2] = glm::vec4(-toEarth, 0.0f);  // sumbu -Z menghadap Bumi
```

Setiap satelit dibangun dari model 3D berformat GLB (Aqua, ICESat-2, dan Landsat 8) yang dimuat dan diskalakan ke ukuran proporsi simulasi. Materialnya dikonfigurasi dengan komponen *specular* yang lebih tinggi `(0.5, 0.5, 0.55)` dan *shininess* 32.0 untuk mereplikasi kilau panel logam dan material komposit yang khas pada badan wahana antariksa. Vektor `toEarth` dihitung dari normalisasi posisi negatif (`-pos`), yang secara geometris selalu mengarah dari posisi satelit menuju pusat Bumi (titik origin). Matriks orientasi akhir digabung dengan matriks translasi posisi orbit, menjamin satelit selalu "menunduk" menatap Bumi ke manapun ia bergerak di sepanjang rel orbitnya.

```glsl
    // Buang piksel sudut agar titik persegi menjadi lingkaran
    vec2 coord = gl_PointCoord - vec2(0.5);
    float dist = length(coord);
    if (dist > 0.5) discard;

    // Gradien cahaya memudar dari pusat
    float alpha = smoothstep(0.5, 0.1, dist);

    // Variasi warna spektral berdasarkan kecerahan
    vec3 coolStar = vec3(0.7, 0.8, 1.0);   // biru-putih (bintang panas)
    vec3 warmStar = vec3(1.0, 0.9, 0.7);   // kuning hangat (bintang dingin)
    vec3 color = mix(coolStar, warmStar, vBrightness);

    FragColor = vec4(color * vBrightness, alpha * vBrightness);
}
```
Penjelasan:
Sistem bintang dibangun secara prosedural tanpa menggunakan aset gambar *skybox* apapun. Sejumlah 2500 titik bintang dibangkitkan pada permukaan bola berdiameter 1600 unit (radius 800) menggunakan distribusi seragam Archimedes: formula `phi = acos(2*rand - 1)` menjamin titik-titik terdistribusi merata di seluruh permukaan bola tanpa penumpukan di kutub, sebuah masalah klasik yang terjadi jika menggunakan distribusi theta-phi biasa. Setiap bintang memiliki dua atribut unik: kecerahan (*brightness*) acak antara 0.3-1.0 dan ukuran (*size*) acak antara 1.0-3.5 piksel. Sebanyak 5% bintang dikategorikan sebagai "bintang raksasa" dengan kecerahan 0.9-1.0 dan ukuran 3.0-5.0 piksel, menciptakan variasi visual yang realistis. Di dalam *Vertex Shader*, efek kedip (*twinkling*) diwujudkan melalui modulasi sinusoidal: kecerahan dikalikan dengan `0.6 + 0.4 * sin(time * 1.5 + brightness * 31.415)`, di mana konstanta irasional 31.415 sebagai *phase offset* menjamin setiap bintang berkedip pada fase yang berbeda-beda dan tidak sinkron. Ukuran titik juga berosilasi dengan frekuensi berbeda `(time * 2.0)` dan fase berbeda `(brightness * 17.3)`, menghasilkan ilusi bintang yang "bernafas" hidup. Di dalam *Fragment Shader*, titik persegi bawaan GPU dikonversi menjadi lingkaran sempurna dengan mem-buang (*discard*) fragmen yang jaraknya dari pusat melebihi 0.5. Gradien cahaya dari pusat ke tepi dihitung menggunakan `smoothstep(0.5, 0.1, dist)` yang menciptakan efek *glow* memudar halus. Warna bintang divariasikan secara spektral: bintang redup cenderung berwarna biru-putih dingin `(0.7, 0.8, 1.0)` merepresentasikan bintang tipe O/B yang panas, sedangkan bintang terang cenderung kuning hangat `(1.0, 0.9, 0.7)` merepresentasikan bintang tipe G/K yang lebih sejuk, mengikuti diagram Hertzsprung-Russell dalam astrofisika. Output akhir `color * vBrightness` dan `alpha * vBrightness` memastikan bintang redup secara proporsional juga lebih transparan, memberikan kesan kedalaman dimensional bahwa bintang yang lebih redup berada lebih jauh di kedalaman galaksi.
